选项题：每行一个选项，模型从中选一个

三种问法

选项：从列表里选一个（意图、部门、话题…）
打分：按档位从低到高（紧急度、危害等级…）
是非：判断是否成立（退款、钓鱼、越狱…）

Laya 更擅长：工单分诊、邮件分类、内容安全、提示护栏。

接口调用示例

请求
POST http://127.0.0.1:8787/api/predict
Content-Type: application/json
请求体（随左侧输入自动更新）

        

        

          
可设参数

          

            

              model
              字符串，选检查点：english / multilingual / typed（对应 laya、laya-multilingual、laya-typed-decisions）
            

            

              state
              对象或字符串。常用 state.text；也可放任意 JSON 字段（如 from / subject / body）
            

            

              questions
              对象，键为题目 id（如 q1），值为题目定义
            

            

              questions.*.type
              题型，三选一：choice 选项 / score 打分 / noul 是非
            

            

              questions.*.instructions
              字符串，要问的问题
            

            

              questions.*.criteria
              choice：对象 {"标签": "说明"}（说明可省略）

                   score：数组，从低到高档位 ["不紧急", "…"]

                   noul：可不填
